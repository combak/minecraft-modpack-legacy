# Minecraft Modpack Legacy
Ich sammle hier alle BakermanLP und BakermanLP Community Modpacks. Hier wird nach und nach alles rein kommen was ich noch auf meiner Platte habe und bei Bedarf noch Anleitungen.

Alle Clients sind MultiMC Instanzen, ich empfehle [Prism Launcher](https://prismlauncher.org/) um diese zu verwenden.
